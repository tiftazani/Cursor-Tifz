# Kandidat Cuciin 1.5.1

APK/AAB bertanda tangan, versionCode 7, target API 36. Belum untuk distribusi produksi dan belum ditinjau Google Play. Lihat [status dan penghambat rilis](../../android/RELEASE_READINESS.md).

APK rilis memakai paket aplikasi versi itu, berbeda dari APK debug lama. Data dan foto lokal aplikasi debug tidak otomatis berpindah. Akun rilis wajib memiliki kata sandi; akun awal tanpa kata sandi ditolak.

AAB disiapkan untuk pengajuan Google Play setelah autentikasi/otorisasi server, migrasi akun/data, dan persyaratan Console diselesaikan. Kunci privat tidak termasuk dalam folder ini. Tautan unduh web lama belum diganti dengan kandidat ini.

Gunakan SHA256SUMS untuk memeriksa kesamaan artefak.
