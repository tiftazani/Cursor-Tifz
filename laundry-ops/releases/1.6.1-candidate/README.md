# Cuciin 1.6.1 (9) — kandidat rilis

APK dan AAB ditandatangani dengan kunci rilis privat Cuciin. APK lolos pemeriksaan sertifikat, non-debuggable, target SDK 36, izin minimum, serta ZIP/ELF 16 KB. AAB lolos `bundletool validate`.

Versi ini memperbaiki referensi cabang pada nota WhatsApp, penerimaan share Google Maps, stok per cabang, dan grafik analytics. Proses operasional menambahkan prioritas keterlambatan serta serah-terima pelanggan.

Kandidat belum dipublikasikan atau ditinjau Google Play. Penghambat keamanan server tetap dijelaskan di `../../android/RELEASE_READINESS.md`.
